# Changesets

Hello and welcome! This folder has been setup by `@changesets/cli` to track changes across the AdminKit monorepo.

To create a new changeset, run:

```bash
pnpm changeset
```

Follow the prompts to specify whether changes are a major, minor, or patch release, and provide a summary for the generated changelogs.

To bump versions and generate changelogs across packages:

```bash
pnpm version-packages
```
